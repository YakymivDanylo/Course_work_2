# Інформаційна система туристичної фірми

## Опис

Десктопний додаток на Python (Tkinter) з використанням PostgreSQL для автоматизації роботи представництва туристичної фірми. Підтримує всі CRUD-операції, права доступу, заявки, функціональні запити, календарі для дат, кирилицю в інтерфейсі.

## Структура проєкту
- `schema.sql` — SQL-скрипт для створення структури бази даних
- `main.py` — основний файл Tkinter-додатку (GUI, екрани, права)
- `queries.py` — функції для роботи з БД, CRUD, агрегації, запити

## Вимоги
- Python 3.8+
- PostgreSQL
- pip install psycopg2-binary tk tkcalendar

## Інсталяція та запуск
1. Створіть базу даних PostgreSQL (наприклад, `tour_agency`).
2. Виконайте скрипт `schema.sql` у вашій БД (через psql або PgAdmin).
3. Встановіть залежності:
   ```
   pip install psycopg2-binary tk tkcalendar
   ```
4. Вкажіть свої параметри підключення до БД у `queries.py` (host, dbname, user, password).
5. Запустіть додаток:
   ```
   python main.py
   ```

## Основний функціонал
- Авторизація (логін, пароль, Forgot Password — лише для адміністратора)
- Додавання користувачів (адміністратор)
- CRUD для всіх сутностей: Турист, Готель, Екскурсія, Агентство, Вантаж, Віза, Група туристів, Фінансовий звіт, Авіарейс
- Всі поля дат — через календар
- Всі grid-и — з кириличними назвами колонок
- Права доступу:
  - **Адміністратор**: повний доступ, додавання операторів, обробка заявок
  - **Оператор**: CRUD, запити, агрегації
  - **Авторизований**: перегляд, пошук, запити, збереження результатів
  - **Гість**: перегляд, подача заявки на підвищення прав
- Заявки: подача (гості), схвалення/відхилення (адміністратор)
- 10 функціональних запитів (рентабельність, фінанси за період, завантаження рейсу, статистика екскурсій, вантажообіг, інформація про туриста, фінансовий звіт групи, зайнятість готелів, туристи для митниці, туристи за період)
- Захист від SQL-ін’єкцій, обробка помилок

## Додатково
- Для тесту додайте користувача-адміністратора напряму в БД або через форму.
- Для дат використовуйте формат YYYY-MM-DD.
- Всі дії супроводжуються повідомленнями про успіх/помилку.
